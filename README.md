A web-based Hotel Booking System developed using Spring Boot, Hibernate (JPA), and MySQL, designed to automate hotel room bookings, manage customer records, and handle billing operations seamlessly.
This project follows a RESTful architecture, using Spring Boot for backend logic and Hibernate ORM for efficient database management — delivering a robust, scalable, and easy-to-maintain solution for hotel management.

Tech Stack
☕ Backend Framework	Spring Boot
🧩 ORM Framework	Hibernate (JPA)
🗄️ Database	MySQL
🌐 Frontend	HTML, CSS, Bootstrap

Key Features

🏠 Room Management — Add, update, and manage room availability.

👥 Customer Management — Register, view, and update guest details.

📅 Booking System — Create, view, and cancel hotel bookings.

💰 Billing Module — Automatically calculate and display total stay charges.

🧾 Hibernate ORM Integration — Simplifies database operations using entity relationships.

🧱 Layered Architecture — Clean separation between Controller, Service, and Repository layers.

☁️ Database Connectivity — Configured with MySQL via Spring Data JPA.
